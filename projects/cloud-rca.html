Project 01 · Explainable AI

Cloud Application Root Cause Analysis

Investigating application data to understand patterns associated with errors and make analytical findings easier to interpret.

Python XGBoost SHAP Data Analysis
5,899 Application traces analysed
3,145 Normal traces
2,754 Erroneous traces

The challenge

Modern cloud applications rely on interconnected services. When errors occur, monitoring data can be difficult to interpret. The goal was to investigate which characteristics of application activity were associated with erroneous behaviour.

My approach

  • Prepared application trace data into structured features describing service activity and trace characteristics.
  • Compared analytical approaches for distinguishing normal and erroneous traces.
  • Investigated which features influenced model predictions.
  • Used explainability methods to examine and interpret the results.

Key takeaway

Predictive performance alone is not enough. Analytical findings also need to be interpretable. Comparing different explanations can provide a clearer picture of patterns in complex application data, while avoiding assumptions that an association proves the actual cause.
