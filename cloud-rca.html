Cloud Application Root Cause Analysis

Explore how machine learning can distinguish normal and erroneous application behaviour and help interpret patterns associated with errors.

The question

Application traces contain complex signals. Predictive models can detect patterns, but their outputs are more useful when people can inspect which features influence a prediction.

Approach

Analysed trace-level data, applied tree-based classification methods, and used feature importance and SHAP to interpret model predictions.

Tools & methods

PythonXGBoostSHAPFeature importance
Scope & limitations
Interpretability can guide further investigation, but model explanations are not proof of the real-world operational root cause. The operational root cause was not independently verified.
